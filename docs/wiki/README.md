## Publish

The wiki is a separate Git repository (`agargya123/waylit.wiki.git`). This checkout cannot access it with the current GitHub account, so a repository collaborator with Wiki access needs to publish the files. On GitHub, open the repository's **Wiki** tab and create the first page if GitHub asks; then use **Clone this wiki locally** and copy these page files into that clone. Commit and push them to the branch already checked out in the wiki clone. The main repository and these source pages are unchanged by publishing.

Copy these files as wiki pages: `Home.md`, `Getting-Started.md`, `SDK-Quickstart.md`, `API-Reference.md`, `Concepts.md`, `Demo-and-Evidence.md`, and `_Sidebar.md`. This handoff README is not a wiki page.
